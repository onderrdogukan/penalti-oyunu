# JavaScript Penaltı Atışı Oyunu

HTML5, CSS3 ve saf (Vanilla) JavaScript kullanılarak geliştirilmiş, web tabanlı dinamik bir penaltı atışı oyunudur.
Bu proje, harici bir kütüphane veya framework kullanılmadan DOM manipülasyonu, CSS animasyonları ve olay güdümlü (event-driven) JavaScript mantığının nasıl kurgulanabileceğini
göstermek amacıyla tasarlanmıştır.

## Oynanış ve Özellikler
* **Dinamik Animasyonlar:** CSS transition ve transform özellikleri kullanılarak akıcı top ve kaleci hareketleri.
* **Olasılık Tabanlı Kaleci Yapay Zekası:** Kaleci hareketleri rastgelelik (randomness) ile birlikte, oyuncunun vuruş yönünü tahmin etmeye yönelik olasılık hesaplamaları (Math.random) içerir.
* **Durum Yönetimi (State Management):** Oyun döngüsü, atış sayısı limitleri (3, 5, 10 atış) ve skor takibi tamamen Vanilla JS değişkenleri ile anlık olarak yönetilir.
* **İnteraktif Arayüz ve Ses Entegrasyonu:** Atış, gol ve kurtarış durumlarına göre dinamik güncellenen skor barları ve HTML5 Audio API ile sağlanan ses efektleri.

## Kullanılan Teknolojiler
* **Geliştirme:** HTML5, CSS3, Vanilla JavaScript (ES6+)
* **Tasarım:** Responsive Flexbox mimarisi, CSS Keyframes/Transitions
* **Medya:** HTML5 Audio API
